# Secte Beaute — 3D viewer & gambar kerja

- `index.html` — viewer 3D online (model desain, warna material asli). Klik furnitur/dinding/pintu/lantai untuk detail & gambar kerja.
- Tombol Plafon / Lampu / Furnitur / Garis untuk sembunyikan & tampilkan; slider POTONG untuk potongan horizontal.
- `offline.html` — versi satu file, bisa dibuka tanpa internet (unduh lalu buka di browser).
- `gk/` — gambar kerja DED Rev.03 per lembar (JPG, 126 lembar).
